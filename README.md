# JYF Security - Sitio Web

Sitio web oficial de JYF Security, empresa de seguridad privada en Chile.

## Características

- Diseño moderno y responsive
- Optimizado para SEO
- HTML5, CSS3 y JavaScript vanilla
- Navegación suave y animaciones
- Secciones completas con todos los servicios
- Formulario de contacto vía mailto

## Estructura

```
jyfsecurity/
├── index.html      # Página principal
├── css/
│   └── style.css   # Estilos
├── js/
│   └── main.js     # JavaScript
├── img/
│   └── favicon.svg # Favicon
└── .htaccess       # Configuración Apache
```

## Despliegue

Subir todos los archivos a la carpeta pública de su hosting (public_html) para el dominio jyfsecurity.cl

## Tecnologías

- HTML5
- CSS3 (Variables CSS, Flexbox, Grid)
- JavaScript (Vanilla)
- Bootstrap Icons
- Google Fonts (Inter)
